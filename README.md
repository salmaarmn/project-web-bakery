# ☀️ Sun & Flour Bakery
Sun & Flour merupakan sebuah brand bakery yang menghadirkan berbagai pilihan produk bakery dengan konsep yang hangat dan menarik. Website ini dikembangkan sebagai media informasi dan promosi untuk memperkenalkan Sun & Flour kepada masyarakat.

Website Sun & Flour menyediakan informasi mengenai profil bakery, katalog produk, serta kontak yang dapat diakses dengan mudah oleh pengunjung.

## Tujuan dan Latar Belakang

Website Sun & Flour dibuat sebagai proyek pengembangan website secara berkelompok untuk menerapkan keterampilan dalam pembuatan website menggunakan HTML dan CSS.

Tujuan pengembangan website ini adalah:
- Memperkenalkan brand Sun & Flour kepada masyarakat.
- Menyediakan informasi mengenai profil dan identitas bakery.
- Menampilkan berbagai pilihan produk melalui katalog online.
- Memudahkan pengunjung memperoleh informasi mengenai produk bakery.
- Menerapkan kerja sama tim dalam pengembangan website.

## Fitur dan Section Website

Website Sun & Flour memiliki beberapa halaman utama, yaitu:

- **Home:** Menampilkan halaman utama, identitas, dan pengenalan Sun & Flour.
- **About:** Berisi profil dan informasi mengenai bakery.
- **Katalog:** Menampilkan berbagai pilihan produk atau menu bakery.
- **Contact:** Menyediakan informasi kontak untuk memudahkan pengunjung menghubungi pihak bakery.

## Teknologi yang Digunakan

Teknologi dan tools yang digunakan dalam pengembangan website:

- **HTML:** Digunakan untuk membuat struktur halaman website.
- **CSS:** Digunakan untuk mengatur desain, warna, tampilan, dan tata letak website.
- **GitHub:** Digunakan untuk menyimpan kode program dan mendukung kolaborasi antaranggota kelompok.
- **Visual Studio Code:** Digunakan sebagai editor untuk menulis dan mengembangkan kode program.

## Cara Menjalankan Website Secara Lokal

Ikuti langkah-langkah berikut untuk menjalankan website Sun & Flour:

1. Pastikan Git sudah terinstal di komputer.
2. Buka terminal atau Command Prompt.
3. Clone repository menggunakan perintah berikut:

   ```bash
   git clone https://github.com/salmaarmn/project-web-bakery.git
   ```

4. Masuk ke folder project:

   ```bash
   cd project-web-bakery
   ```

5. Buka folder project menggunakan Visual Studio Code.
6. Jalankan file `home.html` menggunakan browser atau ekstensi Live Server.
7. Website Sun & Flour siap diakses secara lokal.
